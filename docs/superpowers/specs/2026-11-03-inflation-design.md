# 中美通胀指标

用户选择复用指标目录、收藏、看板和比较图，并要求开发后推送及部署。
新增美国 CPI-U 未季调同比率（FRED CPIAUCNS，units=pc1）与中国全国 CPI 同比率（东方财富 RPT_ECONOMY_CPI / NATIONAL_SAME）。单位均为百分比，观察月份统一以月初标识，不当作发布日期。零、负值有效；缺失保留为空，失败保留旧数据。
复用指标注册与现有采集控制，不新建分析页面。图表增加5年、10年与自定义1–100年；比较图提供中美通胀快捷选择与原始百分比共轴。默认回填最多100年内的可用历史，以支持1–100年筛选，超出已有历史显示真实已有点，允许按指定范围同步。
对照方案：独立通胀页增加重复维护；将中国也接FRED可能有更新滞后；因此采用上述已选复用方案和分国数据源。
