# Atlas Invest Implementation Plan

> **For agentic workers:** use executing-plans and independent parallel domain work; preserve stage commits.

**Goal:** Deliver the specification's usable V1 vertical slice, with truthful source status.
**Architecture:** Next.js React API/UI; normalized PostgreSQL; Python CLI adapters. Explicit isolated Demo repository when DATA_MODE=demo; no Demo prices in PostgreSQL.
**Tech Stack:** Next.js 16, React 19, TypeScript strict, PostgreSQL, Python, Lightweight Charts.
**Spec:** `INVESTMENT_RESEARCH_PLATFORM_SPEC.md`, especially 0, 6.10, 13.

## Global Constraints
- No invented live prices, secrets in browser/export/logs, unauthorized mutations, or incompatible history fallback.
- Each completed milestone has its own checks, status update, commit and push attempt.
- No destructive migration; initial schema only. Preserve supplied documents.

## Review Focus
- Missing keys and upstream schema changes must not produce zero/fresh values.
- Disabled or incompatible fallback must never rewrite a series' definition.
- Production must reject local authentication bypass and protect owner resources.
- Quotas and duplicate requests must persist across server workers in live mode.
- Missing observations and mixed frequencies must retain nulls; no future fill.
