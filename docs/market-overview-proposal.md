# 首页市场总览改造提案

状态：用户已澄清并确认收藏决定主图选项，关联配置可从全部现有指标中增删。按此范围实施。

## 展示与交互

首页右上角新增有边框、底色和星标的“切换主图”区域，显示当前指标名称、自选数量及明显的下拉箭头。下拉选项只来自现有收藏操作使用的第一张观察列表，沿用收藏顺序；提供“管理自选”入口。手机端占一整行，保留可访问的选择标签和键盘操作。

不再限制只能选黄金、汇率与股票指数：所有自选指标均可作为主图，缺历史数据时明确显示暂无历史，不制造走势。取消收藏当前主图后，切换至首个剩余自选；无自选时展示添加引导，不暗中塞入未收藏指标。同一浏览器重新进入页面优先恢复上次仍被收藏的主图；失效后回退首个收藏。

“相关指标”属于当前主图，和收藏列表分别管理。标题旁显示“管理”，打开可搜索、勾选的指标面板。支持添加、移除、保存为空和恢复推荐；保存后刷新、换设备仍保留。切换主图不会覆盖别的主图配置。关联项不要求先收藏，也不会因为加入关联项而自动收藏。

## 实现方式与选择

建议：继续使用现有 Next.js 页面、收藏 API、登录权限与 PostgreSQL。新增以 owner 和主图 seriesId 为键的配置表及独立配置 API，存储相关指标ID；通过小型增量迁移接入，不改动已有自选、研究组件或行情记录。preview/demo 使用各自的本地存储。

另一种方式是只在浏览器本地保存，工作量较小，但手机和电脑配置不一致，因此不推荐。

保存采用显式按钮，失败保留待保存内容并给出重试入口。服务器验证指标存在、禁止自关联与重复、限制单组数量，并沿用现有鉴权与同源校验。页面读取失败不擅自覆盖用户配置。

## 验收与交付

- 收藏、取消收藏、跨页面返回后，主图选项与现有收藏一致；收藏为空时有明确引导。
- 黄金切换到指数时使用不同推荐关系；用户修改只影响当前主图，允许全部删除，刷新后保留，恢复推荐可用。
- 保持现有最新价格与主图末端同步、手动刷新和来源时间展示。
- 验证桌面与390px手机、键盘操作、配置API鉴权及真实PostgreSQL持久化；运行类型、lint、测试和生产构建。
- 仅提交本次文件，保留现有未提交的数据库修复与部署文件。按现有授权推送GitHub；服务器独立构建、迁移后验证并保留旧运行产物。
